# 프로젝트 목표: 카트라이더 역공학 및 Rust 재구현

기존 크레이지레이싱 카트라이더(2004~2023)를 역공학(Reverse Engineering)하여 Rust로 재구현한다.

**최종 목표는 원본 카트라이더와 100% 동일한 게임을 만드는 것이다.**

### 1. 역공학 도구
- REA (Reverse Engineer Anything): https://github.com/morluto/rea
- REA의 Skill 및 사용법을 확인하고 적극 활용한다.
- 필요에 따라 Ghidra, IDA, x64dbg 등 다른 역공학 도구도 활용한다.

### 2. 원본 자료 조사 및 확보
- 웹 검색을 통해 공개된 카트라이더 관련 자료를 최대한 광범위하게 조사한다.
- GitHub, 공개 아카이브, 커뮤니티 등에서 게임 데이터, 맵, 카트, 모델, 텍스처, 파일 포맷 및 분석 도구를 찾는다.
- 적법하게 접근하고 사용할 수 있는 자료는 직접 다운로드한다.
- 확보한 모든 자료를 정리하고 실제 파일 구조와 내용을 분석한다.
- 자료의 출처와 라이선스를 기록한다.

### 3. 개발 우선순위
가장 중요한 것은 **맵, 카트, 레이싱**이다.

원본의 실제 데이터와 프로그램 동작을 분석하여 최대한 동일하게 재현한다.

멀티플레이, 로비, 매치메이킹 등 부가 기능은 우선순위에서 제외한다.

### 4. 기술 방향
- Rust
- Bevy
- 역공학 결과에 따라 적합한 도구와 기술 선택

원본을 충분히 분석한 뒤 구현한다. 추측으로 기능을 만들지 말고 실제 분석 결과를 기준으로 개발한다.

### 5. 첫 번째 작업
아직 게임을 개발하지 마라.

먼저 웹에서 공개된 카트라이더 자료를 검색하고 다운로드한 뒤 분석하라. REA를 비롯한 역공학 도구를 준비하고, 원본 프로그램과 데이터의 구조를 파악하라.

분석 결과를 바탕으로 Rust 재구현을 진행하라.

**최종 목표: 기존 카트라이더의 맵, 카트, 레이싱을 포함한 게임 전체를 100% 동일하게 재현한다.**
